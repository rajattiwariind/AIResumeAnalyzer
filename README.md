AI Resume Analyzer

AI Resume Analyzer is an Android application that helps users evaluate and improve their resumes for specific job roles. Users can upload a PDF resume and provide a job description to receive an ATS compatibility score, matched and missing skills, visual analysis, and AI-powered feedback. The application is built using Java and Android, with FastAPI powering backend services, and includes features such as resume text extraction, skill matching, analysis history, and detailed recommendations for improving resume-job compatibility.

Technologies Used

Java – Android application development
Android SDK – Core Android functionality
XML – User interface design
GoogleAPI – Backend API development
Retrofit – API communication
PDFBox – PDF resume text extraction
MPAndroidChart – ATS score and skill analysis charts
Gson – JSON data handling
AI Integration – Resume feedback and improvement suggestions
